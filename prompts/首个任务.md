# ChatFlow · 首个任务 Prompt（复制给 Codex / Claude / DeepSeek）

你是 ChatFlow（Flutter 跨端 AI 助手）的主编码智能体。
开始前先读：`AGENTS.md`、`docs/design.html`、`docs/development-doc.md`、`docs/agent-spec.md`。

## 任务
把默认计数器 demo 重写为「对话主页」骨架：顶部模型切换 + 消息气泡列表 + 底部输入栏（先用本地假数据，暂不接真实模型）。

## 具体要点
1. 建立 `lib/core/` 目录（纯 Dart，禁止 import Flutter UI）：
   `core/models/message.dart`（MessageRole { system, user, assistant }、Message）。
2. 建立 `lib/theme/design_tokens.dart`（如不存在）并引用其颜色/圆角。
3. 重写 `lib/main.dart`：
   - 顶部 AppBar 左侧菜单、右侧「DeepSeek-R1」模型芯片（可切换假数据）。
   - 中部消息列表：用户气泡右侧主色、AI 气泡左侧白底描边，圆角 14。
   - 底部输入栏：输入框 + 发送按钮；发送后把消息追加进列表，AI 回一条假回复。
4. 会话状态用 Riverpod 管理（如已加依赖）或先用 StatefulWidget，后续迁移。

## 约束（违反即打回）
- Flutter 3.7.12-ohos / Dart 2.19.6，禁止升级到非 ohos 版本，禁止新增非清单依赖。
- 颜色/圆角引用 `design_tokens.dart`，禁止硬编码。
- `core/` 必须纯 Dart、可单测，禁止 import material/widgets。
- 增量修改，不破坏已生成的 android/ohos/web 目录。
- UI 对照 `docs/design.html` 第一屏「对话主页」。
